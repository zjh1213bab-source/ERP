# 本机局域网预览部署

访问地址：`http://192.168.110.69:5173`。本机地址：`http://127.0.0.1:5173`。

## 启动方式

`install-lan-preview.ps1` 注册两个 SYSTEM 计划任务：`ERP-LAN-backend`、`ERP-LAN-frontend`。
触发条件为系统启动，不需要用户登录。任务不限运行时长，守护脚本在子进程退出后退避重启；
守护自身失败由计划任务每分钟重试。安装脚本需管理员权限，可重复执行。

前端 Vite 监听 `0.0.0.0:5173`，固定端口，不自动递增。`/api`、`/uploads` 代理到后端 3100。
前端源码修改由 Vite 热更新。后端读取 `backend/.env` 中的密钥，明确使用
`backend/data/lan-preview.db`，禁用调度；数据库缺失会拒绝启动，避免悄悄生成空库。
原有 3000 服务与旧目录的启动项保留，不接管其数据。

`preview.local.json` 仅存本机 Node 可执行文件路径，不入 Git；迁移电脑时重新填写实际路径。
防火墙规则 `ERP-LAN-Preview-5173-LocalSubnet` 对所有网络配置文件启用，仅允许本地子网 TCP5173。
电脑 IP 改变后访问地址也会改变。电脑需保持开机、联网，睡眠期间无法访问。

## 排查

- 健康检查：`http://127.0.0.1:5173/api/health`。
- 日志：`backend/data/logs/preview-backend.*.log`、`preview-frontend.*.log`。
- 安装结果：`preview-install.local.json`；包含执行时间与成功/失败结果，不包含密钥。
- 取消开机启动：在管理员任务计划程序中禁用上述两个任务；已运行的子进程需单独停止。
- 不要向 Git 提交 `.env`、数据库、上传文件或本机配置。
