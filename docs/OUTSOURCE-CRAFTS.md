# 外发工艺档案与款色明细

开发详情 → 外发工艺：面料工艺、裁后工艺两区。添加后选择款色、工艺档案及工艺厂，填写图片、数量、单价和备注；复制到其他颜色会产生独立行，要求补填款色。

工艺档案复用现有 craft_types（档案 → 工序类别，页面标题为工序/外发工艺档案），支持既有新增、编辑、停用及默认价格。工艺厂选择 factories，电话/地址由服务端读取，不能通过明细伪造。无需新建重复的档案表或权限点。

tech_packs.outsource_json 新增 JSON 文本列，schema.js 定义及 db.js 幂等迁移。逐条记录阶段、款色、档案编号、工艺厂编号、价格数量、图片及备注；金额后端重算。最多200行，行标识唯一，款色必填，档案存在且有效，单价最多两位小数；非法参数事务前拒绝。旧文字说明保留显示。

沿用开发明细事务、updated_at冲突检测、交版锁定、改版审批及复核。改版快照包含外发工艺，复核驳回会恢复；新版本和已完成样衣快照保留这些明细，复用样衣时复制冻结数据，不写回原档案。
