# 工作空间外观

## 简易版：日常使用

点击页面右上角 **外观**。

- **显示与配色**：切换深色／浅色、导航预设或自定义颜色、全局列表每页条数。这些偏好保存在当前浏览器。
- **节假日背景**：管理员上传图片，填写节日名称，调整显示强度、虚化与图片位置，然后点击 **发布全站背景**。
- 背景支持 PNG、JPG、WebP、GIF，最大 3MB。建议横向大图，例如 1920×1080。
- 其他已登录电脑在一分钟内同步；切回浏览器窗口也会立即刷新。
- 点击 **恢复默认背景** 可关闭全站背景。图片显示在页面留白区域，表格、表单保持清晰，打印单据不显示背景。
- 所有弹窗保留明确的关闭／取消按钮，点击空白处不会退出。

## 完整版：实现与维护

### 样式与范围

`frontend/src/assets/workspace.css` 为工作空间设计层，统一导航、顶部栏、表格、按钮、输入框、卡片、弹窗、分页、移动端和登录界面。
业务页及组件的中性色与字体已接入主题变量；业务状态颜色保留含义，现金流和财务明细单独处理深色对比。
新增页面复用 `--bg`、`--surface`、`--ink`、`--ink-soft`、`--ink-mute`、`--line`、`--brand` 等变量。
不要向新页面重新引入固定白底黑字，打印样式使用独立纸张配色。

原有导航自定义颜色继续有效。未配置过导航颜色的浏览器默认使用“雾白”，随深浅色模式调整。

### 数据流与权限

- `GET /api/settings/appearance`：所有已登录员工可读取，包括仅有自助权限的员工。
- `PUT /api/settings/appearance`：仅管理员发布；必须携带当前 `revision`，旧版本返回 409。
- 存储位置：现有 `app_config` 表的 `ui_appearance` 键，无新增表或数据库列。
- 发布记录包含版本、操作人和 UTC 时间。使用数据库事务及锁内复核，防止并发覆盖。
- 背景只接受系统上传的图片路径；不接受外部网址、SVG、HTML、CSS。启用时校验图片存在与参数范围。
- 上传复用现有 `/api/upload`，图片文件保存在现有上传目录；配置只存引用，不保存 Base64。
- 移除背景只移除引用，不删除可能被其他单据使用的图片。
- 外观配置与汇率等业务配置使用独立键，不相互覆盖。
- 不需要新增 AppID、AppSecret、密钥或回调地址。

### 验证

在 `backend` 目录运行：

```powershell
node scripts/test-appearance.js
node scripts/test-workspace-ui.js
node scripts/sweep-workspace-pages.js
npm run rbac
npm run verify:data
```

前端改动后先在 `frontend` 运行 `npm run build`。
专项脚本自建临时库与临时端口，测试夹具带 `__SMOKE` 标记，生成的截图位于 `backend/data/logs/workspace-ui`。
全页面脚本自动读取路由，检查静态业务页的深浅色渲染、严重对比不足、控制台异常与布局裁切；涉及具体单据 ID 的页面仍需使用专项脚本验证。

部署沿用 `deploy/win/reload-lan-preview.ps1`，重启前在线备份，并核对健康接口代码时间戳与磁盘一致。
不要把现场数据库、上传图片、`.env` 或本机配置提交到仓库。
