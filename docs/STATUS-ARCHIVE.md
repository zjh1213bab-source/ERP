## 一、这是什么项目

**跳色科技「衣创 ERP」**——服装外贸一体化企业（生产 + 销售）的 ERP，小单快反模式（定制订单需打样 + 现货订单生产跟踪发美仓）。

- 技术栈：Vue 3 + Vite（前端）· Express + SQLite（后端，`better-sqlite3` → `node:sqlite` 双驱动兜底）· **零依赖 Node 22**，无需 npm install 后端。
- 路线：**全定制开发（路线 C）**，保自由度和自有知识产权。

## 五、关键约定（务必遵守）

1. **禁止 `db.transaction()`**，统一 `db.exec('BEGIN'/'COMMIT'/'ROLLBACK')`。
2. **表结构改动用脚本 `apply-*.js` 建表/扩列，再 `rebuild-schema.js` 重新导出 `schema.js`**（单一来源）。
3. Python 写文件一律 `newline='
'`（历史上 `newline='\
'` 非法参数把 `db.js` 截断成 0 行，教训深刻）。
4. 前端新增组件类名**先 grep 是否重名**（`.ml-tag`/`.stat-row` 都踩过坑）；`.stat-row`/`.stat` 不是全局样式，新页面要自带 scoped 样式。
5. 接口返回 `detail` 对象时，前端别 `{...r}` 摊平，统一 `refresh()` 重拉。
6. `GET /:id` 路由放文件末尾（Express 按声明顺序匹配，会吃掉 `/delegates` 等单段路径）。
7. 用户偏好：继续开发**不要确认、按顺序全做**；**不要用 present_files 打开右侧窗口**，直接文字汇报。
8. 文档同步：每项完成要更新 `CHANGELOG.md`、`docs/API.md`、`docs/DB-SCHEMA.md`、`docs/GAP-ANALYSIS.md`、`README.md` 和记忆。
