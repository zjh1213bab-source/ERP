# 预下单图片录入与已打版商品选择

## 简易版

入口：销售 → 预下单 → 新增预下单。

- 全屏图片上传区支持点击多选、拖入多张图片、点击空白后 Ctrl+V 粘贴。每张新增一款，可留空款式名称；单款另有效果图及最多12张细节图。
- “从样衣管理选择商品”支持按款号/名称搜索、多选。只展示最新锁定且完整完成打版、没有待处理变更的样衣；保存时后端再次校验。
- 填写订单总金额（USD）、付款比例（0–100%）；自动展示约定付款金额。未约定可留空，旧单不默认记零。
- 业务员默认当前账号。设计师、分类、系列、波段、样品来源、PO单号可录入并保存，创建新开发单时带入对应资料。
- 转业务下单保留约定总金额与比例，并初始化约定定金；正式金额仍按商品明细核算，业务二次核对。不会生成收款流水。

## 完整版

### 数据与接口

`pre_orders` 新增8列：`total_usd REAL`、`payment_ratio REAL`、`designer/category/series/wave/sample_source/po_no TEXT`。结构在 schema.js，老库启动时 db.js 幂等补列。无需新增表、权限或外部服务配置。

沿用 POST/PUT `/api/pre-orders`、GET `/:id/order-draft`。新增字段与原订单头、款式、开发资料、事件记录同事务提交；任何异常回滚。编辑及完成继续使用 version CAS，冲突返回409。

金额最多两位小数、0–999999999999.99 USD；比例最多两位小数、0–100。拒绝负数、非法类型、非有限值、指数文本和超范围输入。缺省/空值存 NULL。元数据按字段限制长度。

样衣列表和提交校验共用 `preOrderStyles.approvedArchive()`：公司范围、样衣 locked、流程 done、全部必需阶段 done、最新版本、无 pending/approved 未完成变更。仅前端隐藏不足以替代后端校验。

### 上传与异常

上传沿用已鉴权 `/api/upload`，服务端 MIME/文件头白名单和3MB上限不变。批量逐张上传；失败显示文件名和原因，已成功图片保留。款式最多100条，效果图一张、细节图最多12张。上传期间禁止保存、关闭、移动、删除款式，避免遗漏正在上传的图片。空白区域点击不会关闭录入窗。

新图片款保存后发起已有开发流程，款号仍由版房填写；复用样衣使用冻结版本，不改来源样衣。正式转单会带上样衣编号，避免新版业务下单误判为未选择已打版商品。

### 验证与部署

专项接口59项（含生产 Node 24）、预下单浏览器22项（拖入/粘贴、排序、样衣过滤、付款比例、转单并创建正式订单）、原销售下单77项通过。全量冒烟单公司2209/0、多主体2320/0；权限1148接口/167点/0问题；schema373表/445索引一致；临时库数据体检无残留无孤儿。所有测试均在临时库和独立端口执行。

构建 frontend 后使用本机 `deploy/win/reload-lan-preview.ps1` 重载 SYSTEM 后端。脚本先在线备份，再重启实际 Node 进程，以 health.code_stamp 与磁盘最新代码时间一致为部署依据。无微信、SMTP或AI参数新增。


## 2026-11-06 图片卡片与尺码报价

简易版：预下单图片新款按三列卡片显示，点击空白后 Ctrl+V 新增图片款；卡片图片控件继续支持粘贴细节。每款点击“增加尺码”填写可选颜色、必填尺码、整数数量、USD单价。金额自动计算，全部款式都有报价行时订单总额自动汇总。款号仍由版房填写。

完整版：pre_order_items新增pricing_json TEXT NOT NULL DEFAULT '[]'，schema.js和db.js旧库补列保持一致，不增父子表。POST/PUT预单接口接受items[].size_prices，后端在事务前校验每款最多100行、颜色尺码不重复、数量0–1000000整数、单价0–10000000且至多两位小数；金额按分计算，忽略客户端amount及已报价款的expected_qty。沿用预单乐观锁、事件记录及整体回滚。旧预单无报价行时保持旧金额与数量，不造报价。GET详情及order-draft返回规范化明细，业务下单按颜色尺码分组带入独立单价；空颜色明确显示“待确认”，业务转单需核对。未打版完成仍由原正式下单后端校验拦截。

验证：预单浏览器24项、接口100项（含转单读回、篡改金额、负数/小数数量、重复尺码、非法单价拒绝且无落库），全量2209/2320通过；RBAC0问题，schema373表/445索引一致，数据体检无残留孤儿。部署前在线备份，重启加载补列，核对health源码戳。无新增配置参数或微信配置。


## 2026-11-06 款式唯一、颜色和尺码模板

简易版：选择已完成样衣时，同款不可重复添加。颜色使用业务下单的选项（纯色1、印花001–010、款式1–10），尺码模板从已有模板选取，追加缺少尺码且保留现有金额。图片新款自动命名；保存后在开发管理按业务订单号搜索，可看匹配款数。
