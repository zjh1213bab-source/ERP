# 客服式智能助手

## 使用

“智能助手”页采用工作指引卡片 + 右侧聊天面板；其他业务页右下角可打开同一助手。
用户问题显示在右侧，助手回复显示在左侧，支持快捷选项、后续问题、结构化查询结果和业务页面跳转。
Enter 发送，Shift + Enter 换行；中文输入法选字时 Enter 不发送。
对话只用于查询和指引，审批、报工、库存和收付款仍需在对应业务页面确认提交。
原经营看板保留在“经营概览”，按需展开加载。

## 实现

- `AssistantChat.vue` 同时用于完整页面和全局浮窗，统一气泡、输入、重试及结果显示。
- `assistantChat.js` 保存当前登录会话内的共享对话，路由切换可继续聊天；切换账号、Token 或权限变化时清空，取消旧请求并丢弃迟到的旧响应。
- 查询内容和返回数据不写入 localStorage，不建立新的服务器聊天记录表；原有服务端接口审计保持原行为。
- `navigation.js` 为侧栏和助手业务入口共用的模块导航判断；后台数据授权仍由现有接口负责。
- 手填订单号复用 `/api/orders/find?no=...`，沿用既有公司范围和员工基础信息限制；支持含横线编号，例如 `SCBH-20261103-01`。
- 其他查询沿用 `POST /api/assistant/query {q}`，经营看板沿用 insights/report 接口。
- 网络失败在对话内显示并提供重试；30 秒取消等待；同一会话只允许一个进行中的查询；最多保留 40 条消息，结果默认展示前 8 条，可展开。
- 浮窗只能通过明确的收起按钮或 Esc 关闭，点击页面空白不关闭。适配深浅色及手机窄屏，打印不显示浮窗。

本轮仅调整 Vue 前端和前端 API 请求封装，不新增业务接口、数据库列或依赖，不改变订单和审批规则。
不自动调用外部大模型，不要求额外 AI API Key、微信参数或回调地址。当前问答能力来自现有系统查询与预设流程指引，不冒充真人客服。
