## 一、上岗前必读（所有人都要看）

### 1.1 这套系统在管什么

一句话：**从接单到收到钱，每一步都要留下痕迹，而且前一步没做完，后一步点不动。**

这不是为了管人，是为了出事时能回答三个问题：

- 这单现在卡在谁手上？
- 为什么会卡？（谁在什么时候说了什么）
- 这个数字是哪来的？（能点到明细）

### 1.2 五个必须记住的规则

| 规则 | 为什么 |
|---|---|
| **看不到的按钮 = 你没有这个权限**，不要借别人的账号 | 每个人的操作都记日志。借号做事，出事时记录里是你的名字 |
| **前一步没完成，后一步一定点不动**，系统会告诉你缺什么 | 硬门槛是防返工，不是刁难。提示里都写了去哪补 |
| **金额一律以系统算的为准**，不要自己拿计算器对完就改 | 系统里的价格、成本、毛利都是按同一套口径算的，手工改一处，后面全对不上 |
| **改数据前先想「这个数会被谁用」** | 改库存影响齐套与成本，改交期影响排程，改客户信用影响下单 |
| **出错不要自己删数据**，先截图 + 记下单据号，找对应岗位 | 删了就没法查。系统里绝大多数错误都能反审/冲销，不用删 |

### 1.3 出错了，按这个顺序查

1. **看提示原文**：系统的报错都写清了「哪一步没过、缺什么」，先照着补
2. **看状态**：这单现在是什么状态？状态决定了「下一步该谁做」
3. **看单据**：点开单据详情，找「日志 / 操作记录 / 审批记录」，能看到谁在什么时候做了什么
4. **看关联单**：订单 → 开发单 → 成本单 → 分单 → 工序 → 入库 → 发货，是一条链，卡点往往在上游
5. **还查不出来**：把单据号 + 截图发给对应岗位或管理员，不要自己试

### 1.4 每个岗位都能用的四个功能

| 功能 | 入口 | 用途 |
|---|---|---|
| **工作台** | 登录后默认页 | 待办、逾期、最近订单，每天先看这一页 |
| **异常日清** | 左侧「异常日清」（工作台下面第二个） | **每天上班第一件事**：今天必须处理完的几件事、卡在谁手里、点回原单。见 [08 · 异常日清](08-exception.md) |
| **智能助手** | 左侧「智能助手」 | 用一句话问系统里的数据（如「这个月谁的单最多」） |
| **扫码查询** | 左侧「扫码查询」 | 扫款号/订单号条形码，直接跳到单据 |

## 二、按岗位分册

**先看这个**：[新人上手演练清单](00-演练清单.md) —— 每个岗位 6–8 个「照着做一遍」的任务，比读手册有效。

| 分册 | 岗位 | 主要内容 |
|---|---|---|
| [01 · 销售跟单](01-sales.md) | 接单、报价、客户、开发单发起、现货提案、**售后受理** | 从询价到交期的全过程 |
| [02 · 技术打版](02-tech.md) | 开发单、技术包、工艺、面辅料、供方复审 | 技术确认是订单进生产的前提 |
| [03 · 生产车间](03-production.md) | 排程、工序报工、首件、裁片外发、返工结单 | 报工数据直接进成本与产能 |
| [04 · 仓库采购](04-warehouse.md) | 采购、收货检验、备料领退、库存、美仓发货 | 收货≠可用，检验合格才进库存 |
| [05 · 财务会计](05-finance.md) | 成本审核、往来、总账、税票、预算、定价 | 财务不通过，订单不能分单 |
| [06 · 人事行政](06-hr.md) | 员工、考勤、请假、薪酬、绩效、用印、**办公耗材与服务采购**、**资产工衣与领归**、**行政运营报表**、**薪酬计件与工资核对** | 工资与身份证只有人事和财务看得到 |
| [07 · 系统管理员](07-admin.md) | 账号权限、权限复核、备份恢复、数据导入、**数据导出与订阅（水印与订阅）** | 上线期与日常运维；导出文件带水印，可反查到人 |
| [08 · 异常日清](08-exception.md) | **全岗位通用**：六类归口、今日必办、认领/关闭/复核、标为数据遗留 | 每天第一件事，不分工种 |

## 三、这些图是怎么来的

本手册里的截图**不是人工截的**，由脚本用各岗位自己的账号登录后生成：

```bash
cd backend
node scripts/gen-manual-shots.js              # 全部岗位，42 张
node scripts/gen-manual-shots.js --role=sales # 只生成某一个岗位
```

界面改了以后重跑一次，图就更新了 —— 这样手册不会和系统对不上。

输出位置：`docs/manual/img/<岗位>/<序号>-<页面>.png`
