# 新人上手演练清单（按岗位）

> 用法：新人第一天拿到这份清单，**照着做一遍**，每做完一项自己打勾，由带的人验收。
> 比看手册有效得多 —— 手册是查的，清单是练的。
>
> 建议：用测试单练，练完删掉（草稿可删）。不要拿真实客户单练手。

---

## 通用（所有人，约 20 分钟）

- [ ] 登录，改掉初始密码
- [ ] 看一遍左侧菜单，说清哪些是你用的、哪些不是
- [ ] 打开工作台，说出三个指标的含义
- [ ] 用「扫码查询」扫一张单（或手工输单号）
- [ ] 在「智能助手」问一句：「这个月有多少订单」

**验收**：能自己说清「我每天第一件事看什么」。

---

## 01 销售跟单

- [ ] 建一张订单草稿（自己编个客户订单号，如 `TEST-001`）
- [ ] 提交「接单评审」，三项都确认（找生产、仓库配合）
- [ ] 看开发单状态，确认技术是否已确认
- [ ] 点「技术确认」，观察状态变化
- [ ] 找财务审核成本，再点「分单」（或看财务点）
- [ ] 打开订单详情，找到「打印」按钮，打一张生产工单
- [ ] 在「现货经营」看一个款的补货建议，说出为什么有的款只给「观察」

**验收**：能独立走完「草稿 → 分单」，并说清每一步卡在谁那里。

**容易错的地方**：
- 忘了做接单评审就想技术确认 → 系统会拦
- 定制单选成现货 → 后面打版流程走不了

---

## 02 技术打版

- [ ] 打开一张开发单，把面辅料、工艺、客户要求、尺码四块都看一遍
- [ ] 给一张单做 A1 分工（自制 / 外发 / 复用）
- [ ] 做 A2 供方确认（填单价，不然存不上）
- [ ] 做 A3 复审，然后**故意改一次 A2**，观察 A3 变成「失效」
- [ ] 再重做一次 A3，把技术包核准
- [ ] 在「研发立项」登记一个里程碑，试着跳过顺序（会被拦）

**验收**：能解释「为什么改 A2 会导致 A3 失效」。

---

## 03 生产车间

- [ ] 打开排程，找一张单，看它的工序是怎么排到日期上的
- [ ] 试着发布一个还有硬冲突的排程（会被拦），然后写处理意见再发布
- [ ] 给一道工序报工（合格 10、不良 1），看累计数变化
- [ ] 报工一道没做首件的工序（会被拦），然后做首件、放行，再报
- [ ] 报一次设备停机，看排程里那台设备还能不能排
- [ ] 打开一张外发单，试着发一扎没复核的（会被拦）

**验收**：能说清「报工数据会影响什么」（成本、进度）。

---

## 04 仓库采购

- [ ] 建一张采购单 → 下单 → 收货
- [ ] **只点收不检验**，去库存看数量有没有变（不会变）
- [ ] 走请检 + 检验合格，再看库存（变了）
- [ ] 给一张单备料（看可用量减少、账面不变）
- [ ] 发料（看账面减少、占用释放）
- [ ] 做一次盘点，故意留一个不填（提交不了）
- [ ] 补上数量、差异写原因、落账
- [ ] 在「美仓发货」看一张缺货的单，看它标了什么

**验收**：能分清「账面 / 占用 / 可用」三个数。

---

## 05 财务会计

- [ ] 打开一张成本单，把七层成本一个一个指出来
- [ ] 看费用池的分摊结果，核对「分摊合计 = 池额」
- [ ] 审核通过一张成本单，然后让销售去点分单（应该能点了）
- [ ] 登记一笔收款，核销到发票
- [ ] 生成一次凭证，看借贷是否平
- [ ] 打开「八项关账检查」，逐项看哪项没过
- [ ] 看一张价格本，找到「成本漂移」提示

**验收**：能说清「成本审核为什么是订单分单的闸门」。

---

## 06 人事行政

- [ ] 建一个员工档案（测试用，练完改离职）
- [ ] 在「组织编制」给这个员工登记任职（占编）
- [ ] 给一个员工打卡（只能给自己打，试别人的会被拦）
- [ ] 提交一张请假单（自己提自己的），再审批
- [ ] 生成一批薪酬，看明细里的扣款来源
- [ ] 走一次用印申请：申请 → 审批 → 用印 → 归还
- [ ] 查一个已离职员工的记录（能查到，说明没丢）

**验收**：能说清「为什么工资只有几个人能看到」。

---

## 07 系统管理员

- [ ] 建一个测试账号，给一个主岗，登录看菜单对不对
- [ ] 给这个账号加附加岗，刷新看多出来什么
- [ ] 在「权限复核」给这个账号收回一个权限，**写理由**，然后再登录看按钮是否消失
- [ ] 直接调接口试一下（用浏览器开发者工具或 curl），确认后端也拒（403）
- [ ] 做一次备份，下载下来，校验一次
- [ ] 跑一次恢复演练（prepare → 重启 → verify）
- [ ] 导一次客户数据（用模板，先预览，看错误行，再提交）
- [ ] 在「操作日志」找到刚才这些动作

**验收**：能说清「为什么收回权限要写理由」「为什么恢复要重启」。

---

## 带人的人怎么验收

不要问「会不会」，让对方**做一遍给你看**，重点看三件事：

1. **卡住的时候会不会看提示**（而不是直接问人）
2. **改数据前会不会想「这个数被谁用」**
3. **出错时会不会截图留证**（而不是删了重来）

这三条会了，剩下的都能自己摸索出来。
