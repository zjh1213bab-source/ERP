# 预下单与业务订单参考界面

## 简易版

预下单采用紫色分类工具栏及九列表格；点击单号、款式或详情可查看并继续编辑、完成预单和转业务下单。图片点击放大，配置可选择显示列。业务订单采用蓝色筛选和十三列表格，商品按款号缩略图展示，支持筛选、分页和逐款打版进度查看。新增业务下单保持全屏基础信息、商品信息、其他信息三段，底部固定金额与保存操作。

新增订单初始为空，仅默认当前业务员；商品选择仍只取样衣管理已完成打版的锁定版本。多款独立数量、价格、物料、颜色尺码及订单级定金合计逻辑不变。

## 完整版

### 数据流程与接口

- GET /api/orders?view=reference：先沿用订单主体范围过滤，再附加该范围内的订单商品、对应打版版本与状态、成本审核状态、有效附件及生产节点完成数。未带 view 的旧接口输出保持兼容。
- GET /api/pre-orders：附加 missing_details、pattern_running、pattern_complete_unordered、finance_passed 只读分类。财务通过取已转正式订单的实际成本审核通过事实，不额外创建预单财务审批。
- 点击业务下单使用原 SalesOrderEntry：基础信息→选择已打版样衣→逐款颜色尺码数量及物料→其他信息和金额→原后端校验及事务落库。
- 列表和筛选不写库、不重算历史金额；订单美元金额直接使用已保存 total_usd。打版进度按订单商品对应技术单读取，未建流程不借用其他款式的流程。

### 表结构、权限与异常边界

无表结构、权限点和状态机变更。列表投影只读取现有父子表，已删除附件与非 HTTP/本地上传链接不显示。原下单后端参数校验、重复单号、版本冲突、事务回滚均沿用。网络失败显示错误，不创建替代订单。弹窗只通过明确按钮关闭，不支持点击遮罩退出。

分页默认12条，可选24/48/96；筛选后回到第一页，页数缩减时纠正当前页。预单列设置仅保存在当前浏览器 localStorage，业务数据仍在数据库。
