## 6. 已知限制

1. 接口限流为**内存滑动窗口**，进程重启清零；多实例部署需换 Redis。
2. 事件 `dispatch` 目前需手动或外部定时触发，未内置调度器。
3. 接入点 API Key 明文存储（仅掩码展示），生产需改哈希。
4. 客户商城未做在线支付；对账资料按订单与授权文件提供。
5. `orders` 表无 `total_qty` 字段，件数由明细汇总，报表口径一致但对大表需注意性能。
6. 备份恢复需**重启生效**，无法热切换。
